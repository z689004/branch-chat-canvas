# 分支对话 AI 画布工具 — 项目文档

## 1. 项目概述

### 一句话需求
> 做一个对话画布工具：在 AI 回答里选中任意一段文字，一键新建独立子对话分支，节点连线可视化，支持无限分叉。

### 项目定位
本项目是一个 **网页版（B/S 架构）对话画布工具**。它摆脱传统线性聊天模式，以「对话树」为核心：AI 的每一条回答都是一个节点，用户可以从回答中**划选任意一小段文字**，以该片段为上下文拉出一个**独立的子对话分支**；子分支可以继续划词、继续向下分叉，无限深度。所有节点以卡片形式展示在无限画布上，通过连线表达父子关系，支持自由拖拽。

### 核心特点
| 特点 | 说明 |
| ---- | ---- |
| 树状分支对话 | 不是线性聊天，一条回答可以长出多个独立追问分支 |
| 片段级选中 | 精确选中一小段文字作为子对话上下文，而非整条消息 |
| 无限分叉 | 子分支可继续选中文字继续新建下一级分支 |
| 可视化画布 | 节点卡片 + 连线，自由拖拽、缩放、平移 |
| 浏览器即用 | B/S 架构，任意设备打开浏览器访问网址即可使用，无需安装客户端 |
| 流式输出 | AI 回答打字机效果实时渲染 |

### 与现有方案的区别（为什么自己做）
| 方案 | 局限 |
| ---- | ---- |
| Obsidian + Spider 插件 | 必须安装 Obsidian 客户端，陌生设备无法使用；移动端体验差 |
| ChatGPT / Claude 原生分支 | 只能整条消息分叉，不能选中片段作为独立上下文 |
| 普通聊天工具 | 线性对话，无法多分支对比、局部深挖 |

## 2. 需求分析

### 2.1 核心功能需求
1. 创建根会话（主会话）：用户发送提问，AI 返回回答，生成第一个根节点卡片。
2. 文本划选：在 AI 返回的文本区域，鼠标选中任意一段文字。
3. 悬浮按钮：选中文字后自动弹出【基于选中内容新建分支对话】按钮。
4. 新建子分支：点击按钮，生成新的子会话节点，自动建立父子连线。
5. 子分支追问：用户在子节点输入框提问，默认携带选中片段作为上下文发给大模型。
6. 无限分叉：子节点内同样支持划选文字、继续创建下一级分支，无层级限制。
7. 流式渲染：AI 回答以打字机效果实时展示在节点卡片内。

### 2.2 交互流程
```
[用户提问] → [AI回答 → 生成根节点卡片]
                    │
          (划选一段文字 → 弹出按钮)
                    │
        [点击【基于选中内容新建分支对话】]
                    │
        [生成子节点 + 自动建立父子连线]
                    │
        [子节点内继续提问 → AI基于选中片段回答]
                    │
        (子节点内再次划词 → 继续向下分叉,无限重复)
```

### 2.3 上下文模式（子分支追问时生效，可切换）
| 模式 | 说明 | 适用场景 |
| ---- | ---- | ---- |
| 模式A：精简模式 | 仅使用选中的片段作为上下文，干净聚焦 | 针对局部文本深挖、追问细节 |
| 模式B：完整模式 | 继承父节点全部对话历史 + 选中片段 | 保留完整上下文链路的连续讨论 |

> 默认推荐使用精简模式；完整模式适合需要上下文连贯性的深度讨论。

### 2.4 节点基础操作
- 节点卡片拖拽移动，连线自动跟随
- 节点折叠 / 展开子树
- 删除节点（连带删除该节点所有子分支）
- 节点标题重命名（默认自动生成，可自定义）
- 画布平移、缩放、自适应视图、清空画布

## 3. 技术选型方案

### 方案A：快速原型（优先推荐，快速验证交互）
> 适合：先跑通核心交互逻辑，验证产品体验，单人开发上手快。

| 层级 | 技术选型 | 说明 |
| ---- | ---- | ---- |
| 前端 | Vue3 + VueFlow + Element Plus | VueFlow 专门实现节点/连线/无限画布拖拽；Element Plus 提供弹窗、输入框等组件 |
| 后端 | Python + FastAPI + LangChain / Ollama | 大模型调用、SSE 流式输出、树形数据处理代码简短，开源示例多 |
| 模型 | 云端 API（DeepSeek / 豆包 / OpenAI）或本地 Ollama | 灵活切换，支持离线模型 |
| 存储 | Redis（原型阶段缓存）/ SQLite（持久化） | 对话树以 JSON 结构存储 |

### 方案B：工程正式版（后续并入 SpringBoot 项目）
> 适合：稳定上线，和你现有智慧养老、电商项目技术栈统一。

| 层级 | 技术选型 | 说明 |
| ---- | ---- | ---- |
| 前端 | Vue3 + VueFlow | 同上 |
| 后端 | SpringBoot + SpringAI / LangChain4j + MySQL + Redis | 与你现有技术栈统一，高并发稳定，方便接入微服务、MQ、Nacos |
| 存储 | MySQL 持久化对话树数据，Redis 缓存会话与流式状态 | 数据可靠，支持多用户 |

### 选型建议
- 先按 **方案A** 快速做出 Demo 验证交互；
- 效果验证通过后，若需并入现有 Java 项目，再迁移 **方案B**；
- 或保留 Python 后端，通过 HTTP/SSE 接口被 Java 服务调用（成本更低）。

## 4. 数据结构设计

### 4.1 会话节点对象（核心）
```json
{
  "nodeId": "uuid-xxxx",
  "parentId": "uuid-root",
  "title": "节点标题（自动生成或用户自定义）",
  "selectedContext": "从父节点选中的文本片段，子分支的基准上下文",
  "contextMode": "simple",
  "messages": [
    { "role": "user", "content": "用户提问" },
    { "role": "assistant", "content": "AI回答内容" }
  ],
  "createTime": "2026-11-03 16:00:00",
  "updateTime": "2026-11-03 16:00:00",
  "isCollapsed": false
}
```

| 字段 | 说明 |
| ---- | ---- |
| `nodeId` | 节点唯一标识（UUID） |
| `parentId` | 父节点 ID，根节点为 `null` |
| `title` | 节点标题，默认根据提问内容自动生成，支持修改 |
| `selectedContext` | **关键字段**：新建分支时选中的原文片段，子分支的基准上下文 |
| `contextMode` | 上下文模式：`simple` 精简 / `full` 完整 |
| `messages` | 当前节点自己的对话消息数组 |
| `isCollapsed` | 子树是否折叠 |

### 4.2 整棵对话树
```json
{
  "treeId": "tree-001",
  "nodeList": [],
  "createTime": "2026-11-03 16:00:00",
  "updateTime": "2026-11-03 16:00:00"
}
```

| 字段 | 说明 |
| ---- | ---- |
| `treeId` | 一棵树的唯一 ID，一个画布对应一棵树 |
| `nodeList` | 全部节点数组，前端据此渲染节点与连线 |

### 4.3 树形关系说明
- 父子关系通过 `parentId` 表达，前端由 VueFlow 根据 `nodeId` / `parentId` 自动生成连线；
- 删除节点时，递归删除所有 `parentId` 指向该节点的子孙节点；
- 拖拽节点只改变画布坐标，不改变树形结构。

## 5. 后端接口清单

| 接口 | 方法 | 说明 |
| ---- | ---- | ---- |
| `/api/tree/create` | POST | 创建一棵全新对话树（生成根节点） |
| `/api/tree/get` | GET | 获取整棵对话树全部节点数据，前端渲染画布 |
| `/api/node/send` | POST | 节点内发送提问，调用大模型，SSE 流式返回回答 |
| `/api/node/create-child` | POST | 根据父节点 ID + 选中的文本，创建子节点 |
| `/api/node/delete` | DELETE | 删除指定节点（连带它的所有子分支） |
| `/api/node/update` | PUT | 修改节点标题、折叠状态、上下文模式 |
| `/api/tree/export` | GET | 导出对话树：Markdown / Mermaid / JSON |

### 关键接口示例
```json
// POST /api/node/create-child
{
  "parentId": "uuid-root",
  "selectedContext": "SpringAI提供了统一的大模型调用抽象层",
  "contextMode": "simple",
  "title": "关于SpringAI抽象层的追问"
}
```

```json
// POST /api/node/send（SSE 流式）
{
  "nodeId": "uuid-child-01",
  "content": "这句话怎么理解？举个例子"
}
// 响应：text/event-stream，逐段返回 AI 回答
```

## 6. 前端核心能力

1. **文本选中监听**：监听 assistant 回答区域的文本选择事件（`mouseup` / `selectionchange`）
2. **悬浮按钮**：选中文字后，在选区附近弹出【基于选中内容新建分支对话】按钮
3. **VueFlow 画布**：节点卡片渲染、自动连线、节点拖拽、画布缩放与平移
4. **SSE 流式渲染**：打字机效果展示 AI 返回内容
5. **节点操作**：折叠子树、删除节点（含子树）、重命名标题、切换上下文模式
6. **画布操作**：平移、缩放、自适应视图、清空画布
7. **数据持久化**：保存/加载对话树，刷新页面不丢失

## 7. 后续扩展功能清单

| 扩展功能 | 说明 | 优先级 |
| ---- | ---- | ---- |
| 分支对比 | 同时打开多个分支，并排对比不同追问结果 | 高 |
| 导出 | 整棵对话树导出 Markdown / Mermaid / PDF | 高 |

| 节点注释 | 给会话卡片添加备注标签 | 低 |
| 会话分享 | 生成分享链接，其他人只读查看对话树 | 中 |
| 多模型切换 | 每个节点可单独选择不同大模型 | 中 |

## 9. 部署说明

### 原型版（FastAPI）
- 后端：`uvicorn main:app --host 0.0.0.0 --port 8000`
- 前端：构建后由 Nginx 托管，或 FastAPI 静态托管
- 模型：支持本地 Ollama 或云端 API，通过环境变量配置

### 正式版（SpringBoot）
- 打包 Jar，部署到服务器，Nginx 反向代理
- 公网访问地址：`https://your-domain.com`
- 任意设备浏览器打开即用，无需安装客户端

### 使用场景优势
- 电脑、手机、平板、陌生设备：只要能打开浏览器就能用
- 解决 Obsidian 只能本机安装、陌生设备不可用的痛点
