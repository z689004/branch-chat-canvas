# v1.1.1 — 笔记 / 收藏夹

> 把一次 AI 对话变成一棵**可以持续分叉的树**：在无限画布上提问，AI 流式回答；
> **划选回答中的任意一句话**，一键长出一个独立子分支继续深挖，无限嵌套。
>
> 本版新增一个**独立的笔记本子**：聊到好用的提示词、重要的知识点、值得记的结论，
> 随手收藏进来，来源自动记着；平时的想法也能直接写下，攒着以后翻。

线性聊天窗口里，问题越聊越偏、思路汇不拢；这里每个想法都是画布上的一个节点，
哪条线索值得深入就分叉哪条，哪条不需要就整枝剪掉。

## 本次更新（v1.1.1）

**新增：笔记 / 收藏夹**

- **划词收藏** — 在 AI 回答或自己的提问里划选一段文字，弹出面板点「📝 收藏」，
  自动记录来源：来自哪个画布、哪个节点、是 AI 说的还是你说的
- **整条收藏** — 鼠标悬停任意消息，右侧出现 📝 小按钮，一键收藏整条
- **手动记录** — 笔记面板顶部输入框直接写，`Ctrl + Enter` 保存
- **右侧笔记面板** — 画布右侧圆形 📝 入口（带条数徽标），点击展开；
  支持关键词搜索（内容与来源都能搜）、复制、编辑、删除（二次确认）、
  长文展开收起、底部一键清空
- **快捷开关** — `Ctrl + J` 展开 / 收起，`Esc` 关闭
- **本地存储** — 存浏览器 localStorage，刷新页面不丢，上限 500 条防膨胀；
  桌面版与网页版共用同一份笔记

**新增：系统托盘驻留**

- 程序启动后常驻 Windows 右下角通知区域；新图标默认收在托盘的
  「显示隐藏的图标 ^」里，可右键任务栏把它拖到常显区
- 主窗口点最小化（或 Win+D）时自动收进托盘，任务栏不留空壳
- 左键托盘图标 / 菜单「打开主界面」：唤回并激活主画布窗口
- 右键托盘图标菜单：打开主界面、显示悬浮球（带勾选状态）、退出软件

**修复**

- 关闭主窗口时，悬浮球与后台服务一起退出；此前关掉软件后桌面上会留下一个
  点不开主窗口的悬浮球，进程也一直挂着不释放端口
  （用悬浮球「收起」主窗口不受影响，仍可随时从球里唤回）
- 新增单实例保护：程序已在运行时再次双击 exe / 点任务栏图标，会直接唤起
  已运行实例的主界面（此前会卡住无反应或拉起第二个进程）
- 托盘 / 悬浮球上修改设置后，主界面设置面板实时同步（此前开关状态不刷新、
  再点击时方向错乱，表现为「点开关没反应」）
- 从托盘唤起主窗口时强制置前显示，不再只在任务栏闪烁

## 核心功能

**对话与分支**
- ✂️ **划词分叉** — 在 AI 回答里选中一段文字，弹出面板，点「精简 / 完整」立即创建子分支并自动连线
- 🌳 **无限嵌套** — 子分支的回答同样可以划词继续分叉，思路树随对话生长
- 🎛️ **两种上下文模式** — 精简：只围绕选中片段展开；完整：继承祖先链全部对话 + 各级选中片段，可随时切换
- 🫧 **流式输出** — SSE 打字机效果，回答实时渲染 Markdown

**画布操作**
- 🖱️ **节点操作** — 卡片拖拽（连线跟随）、八向自由缩放、折叠/展开子树、重命名、删除含子树、右键菜单、批量操作
- 📐 **金字塔树形布局** — 根节点顶部居中、逐层向下展开，一键整理布局、适应视图
- 🗺️ **小地图** — 缩略导航，按分支着色；缩放百分比常驻画布底部
- ↩️ **撤销 / 重做** — 整树快照，误删分支可回退

**笔记与收藏**
- 🗒️ **随手收藏** — 划词收藏 / 整条收藏 / 手动记录三种方式，适合攒提示词、知识点、结论与自己想法

**桌面端**
- 🫧 **桌面悬浮球** — 42px 应用图标球，始终置顶，自动贴边吸附；左键直达快速对话，右键开菜单
- 📌 **系统托盘驻留** — 最小化收进右下角托盘；左键托盘图标唤回主界面，右键菜单可开关悬浮球、退出软件
- 🪟 **快速对话小窗** — 独立置顶小窗，标题栏拖动移动、八方向自由缩放，位置与大小自动记忆
- 🖥️ **独立应用窗口** — 基于系统 WebView2 渲染，不依赖也不打开浏览器，无控制台黑窗

**数据与模型**
- 🤖 **多模型** — 任何 OpenAI 兼容 API（DeepSeek / 豆包 / 通义 / 智谱 / OpenAI…）、本地 Ollama、无 Key 演示模式
- 🔑 **多密钥档案** — 多套 Key 分组管理，支持真实连通性测试（校验 Key、测延迟、拉取可用模型一键切换）
- 🗂️ **多画布** — 多个话题并行互不干扰，可重命名、清空对话、删除画布
- 📤 **导出与备份** — Markdown、Mermaid、网页快照 HTML（含画布结构图）、JSON 备份与导入还原
- 💾 **数据自主** — 全部存本地 JSON 文件（桌面版）或浏览器 localStorage（单文件版），不经过任何第三方

## 下载与使用

`BranchChatCanvas.exe` — Windows x64 单文件，约 28 MB。

双击运行，等待 5~10 秒解包后打开独立应用窗口，不依赖也不打开浏览器。

上手三步：输入第一个问题生成根节点 → 在回答里划选一段文字 → 点「精简」或「完整」长出子分支。

数据保存在 exe 同级的 `data/` 目录，整个文件夹拷走即可带着对话迁移；端口自动挑空闲值，多开互不冲突；不填 Key 也可进演示模式。

SHA256：`8d8695786b268c9bd8b6bc31f22ba2fbec9ec1449abae2731d9dcaaa9652cea3`

## 已知限制

- 仅提供 Windows 版本，依赖系统 WebView2 运行时（Win10/11 通常自带）
- 未签名程序可能被 Defender 误报，选择「仍要运行」或加入白名单即可
- 首次启动解包 3~8 秒属正常
- 笔记存于浏览器本地，清理应用数据会一并清除；重要内容建议同时导出
