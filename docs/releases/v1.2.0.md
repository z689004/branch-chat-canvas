# v1.2.0 — 快速对话真正可用

> 这一版几乎全在补「快速对话」（悬浮球里那个小窗）的体验坑：
> **会话被删了不再变成死状态**、**能像主界面一样划词建分支**、**一眼看出它对应哪张卡片**。
>
> 顺手把画布空态、八方向缩放和悬浮球阴影一起收拾了。

## 本次更新（v1.2.0）

**快速对话（悬浮球 / 悬浮速记）**

- **删掉也能自愈** — 此前删掉悬浮球绑定的画布、或只删掉那张会话卡片，
  快速对话就只会回一句「对话树不存在」，消息彻底发不出去。现在无论
  删画布还是删会话，打开面板或发消息时都会自动补一个根会话接着聊，
  画布本身保留不动
- **划词建分支** — 在快速对话里选中一段文字（≥4 字）浮出「⚡ 精简 / 📚 完整」，
  生成子分支后小窗直接切到该分支；顶部面包屑显示分支标题，一键「回到主会话」；
  下次展开还停在这条分支上
- **文字能选中了** — 悬浮窗此前整体禁选，且浏览器残留的光标会让拖选
  「怎么拖都选不中」（点过按钮/标题栏后尤其明显），两处都修了
- **⚡ 徽标** — 主画布里那张和快速对话共用的卡片会带「⚡ 快速对话」标记，
  不用猜它对应哪个会话

**画布**

- **空画布有出口** — 把所有对话都删完后不再是一片空白，会出现
  「＋ 新建一个对话」入口，也可以另开一块新画布
- **缩放更跟手** — 拖左边 / 上边缩放时窗口位置会滞后半拍（CSS 过渡与拖动叠加），
  现在八个方向拖动都逐帧跟手

**桌面**

- **悬浮球阴影收窄约 2/3** — Win11 没有单独调系统阴影浓淡的接口，
  改用小圆角窗口自带的轻投影，球边缘干净很多

**工程**

- 新增 6 个自动化回归脚本（快速对话自愈 5 条路径、划选建分支 16 项、
  空画布 8 项、徽标 7 项、八方向缩放探针、阴影探针）

## 核心功能（同 v1.1.2）

**对话与分支**
- ✂️ **划词分叉** — 在 AI 回答里选中一段文字，弹出面板，点「精简 / 完整」立即创建子分支并自动连线
- 🌳 **无限嵌套** — 子分支的回答同样可以划词继续分叉，思路树随对话生长
- 🎛️ **两种上下文模式** — 精简：只围绕选中片段展开；完整：继承祖先链全部对话 + 各级选中片段
- 🫧 **流式输出** — SSE 打字机效果，回答实时渲染 Markdown

**画布操作**
- 🖱️ **节点操作** — 拖拽、八向缩放、折叠/展开子树、重命名、删除含子树、右键菜单
- 📐 **金字塔树形布局** — 一键整理布局、适应视图；🗺️ 小地图按分支着色
- ↩️ **撤销 / 重做** — 整树快照，误删分支可回退
- ⚙️ **设置中心** — 工具栏悬浮面板；响应式收纳；自定义画布背景、透明度、整套配色

**笔记与收藏**
- 🗒️ **随手收藏** — 划词收藏 / 整条收藏 / 收藏节点（⭐，含对话快照）/ 手动记录，
  面板分类筛选 + 搜索，本地保存

**桌面端**
- 🫧 **桌面悬浮球** — 应用图标球，置顶、不占任务栏、贴边吸附；左键直达快速对话
- 📌 **系统托盘驻留** — 最小化收托盘；左键唤回主界面，右键菜单开关悬浮球、退出
- 🪟 **独立应用窗口** — 基于系统 WebView2 渲染，不依赖也不打开浏览器

**数据与模型**
- 🤖 **多模型** — 任何 OpenAI 兼容 API（DeepSeek / 豆包 / 通义 / 智谱 / OpenAI…）、本地 Ollama、演示模式
- 🔑 **多密钥档案** — 多套 Key 分组管理，真实连通性测试
- 🗂️ **多画布** — 多个话题并行；📤 导出 Markdown / Mermaid / HTML / JSON 备份
- 💾 **数据自主** — 全部存本地，不经过任何第三方

## 下载与使用

`BranchChatCanvas.exe` — Windows x64 单文件，约 28.4 MB。

双击运行，等待 5~10 秒解包后打开独立应用窗口，不依赖也不打开浏览器。

数据保存在 exe 同级的 `data/` 目录（含笔记与外观设置的浏览器数据 `data/webview/`），
整个文件夹拷走即可带着对话和设置一起迁移；端口自动挑空闲值；不填 Key 也可进演示模式。

SHA256：`dab927f89532842f22d5851d55054ddac4695c28b63b77f14a1d282c2f9d1364`

## 升级提示

- 从任何旧版本直接替换 exe 即可，`data/` 目录保持原样不动
- 如果旧版快速对话已经卡在「对话树不存在」，升级后第一次打开面板会自动补回会话
- 快速对话补回会话后，主画布不会立刻刷出那张卡片，切一下画布或重启即可看到

## 已知限制

- 仅提供 Windows 版本，依赖系统 WebView2 运行时（Win10/11 通常自带）
- 未签名程序可能被 Defender 误报，选择「仍要运行」或加入白名单即可
- 首次启动解包 3~8 秒属正常
- 笔记存于 `data/webview/` 下的浏览器本地存储，删掉该目录会一并清除；重要内容建议同时导出
