# v1.1.2 — 设置不再丢失

> 修复一个影响所有人的问题：**改过的主题、画布背景、配色和笔记，关掉软件再打开就没了。**
>
> 现在设一次永久保留，重启、关机、重新打开都不丢；而且这些设置跟着 `data/` 文件夹走，
> 换电脑时整个文件夹拷走就能一起带过去。

如果你在用 v1.1.1，建议升级到本版；v1.1.1 及更早版本每次关闭都会清掉外观设置与笔记。

## 本次更新（v1.1.2）

**修复**

- **设置关掉软件就丢**：主题、画布背景、自定义配色、笔记此前每次重启都恢复默认。
  根因是桌面窗口默认跑在 WebView2 隐私模式，关闭时会把浏览器数据目录整个删掉；
  现改为固定数据目录保存，配置跨启动保留
- **数据迁移更完整**：笔记与外观设置现在存放在 `data/webview/`，
  整个 `data/` 文件夹拷走时，对话、笔记、主题一起迁移（此前笔记不随 `data/` 走）

**其他**

- 未改动的功能与 v1.1.1 完全一致，界面与交互无任何变化

## 核心功能（同 v1.1.1）

**对话与分支**
- ✂️ **划词分叉** — 在 AI 回答里选中一段文字，弹出面板，点「精简 / 完整」立即创建子分支并自动连线
- 🌳 **无限嵌套** — 子分支的回答同样可以划词继续分叉，思路树随对话生长
- 🎛️ **两种上下文模式** — 精简：只围绕选中片段展开；完整：继承祖先链全部对话 + 各级选中片段
- 🫧 **流式输出** — SSE 打字机效果，回答实时渲染 Markdown

**画布操作**
- 🖱️ **节点操作** — 拖拽、八向缩放、折叠/展开子树、重命名、删除含子树、右键菜单
- 📐 **金字塔树形布局** — 一键整理布局、适应视图；🗺️ 小地图按分支着色
- ↩️ **撤销 / 重做** — 整树快照，误删分支可回退
- ⚙️ **设置中心** — 工具栏悬浮面板；响应式收纳；自定义画布背景、透明度、整套配色

**笔记与收藏**
- 🗒️ **随手收藏** — 划词收藏 / 整条收藏 / 收藏节点（⭐，含对话快照）/ 手动记录，
  面板分类筛选 + 搜索，本地保存

**桌面端**
- 🫧 **桌面悬浮球** — 应用图标球，置顶、不占任务栏、贴边吸附；左键直达快速对话
- 📌 **系统托盘驻留** — 最小化收托盘；左键唤回主界面，右键菜单开关悬浮球、退出
- 🪟 **独立应用窗口** — 基于系统 WebView2 渲染，不依赖也不打开浏览器

**数据与模型**
- 🤖 **多模型** — 任何 OpenAI 兼容 API（DeepSeek / 豆包 / 通义 / 智谱 / OpenAI…）、本地 Ollama、演示模式
- 🔑 **多密钥档案** — 多套 Key 分组管理，真实连通性测试
- 🗂️ **多画布** — 多个话题并行；📤 导出 Markdown / Mermaid / HTML / JSON 备份
- 💾 **数据自主** — 全部存本地，不经过任何第三方

## 下载与使用

`BranchChatCanvas.exe` — Windows x64 单文件，约 30 MB。

双击运行，等待 5~10 秒解包后打开独立应用窗口，不依赖也不打开浏览器。

数据保存在 exe 同级的 `data/` 目录（含笔记与外观设置的浏览器数据 `data/webview/`），
整个文件夹拷走即可带着对话和设置一起迁移；端口自动挑空闲值；不填 Key 也可进演示模式。

SHA256：`931df9cfa2030e0bd18940e2818897d698279cbf6d4c43db3907e04b774b4041`

## 已知限制

- 仅提供 Windows 版本，依赖系统 WebView2 运行时（Win10/11 通常自带）
- 未签名程序可能被 Defender 误报，选择「仍要运行」或加入白名单即可
- 首次启动解包 3~8 秒属正常
- 笔记存于 `data/webview/` 下的浏览器本地存储，删掉该目录会一并清除；重要内容建议同时导出
