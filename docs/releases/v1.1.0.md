# v1.1.0 — 悬浮速记与画布操作打磨

> 把一次 AI 对话变成一棵**可以持续分叉的树**：在无限画布上提问，AI 流式回答；
> **划选回答中的任意一句话**，一键长出一个独立子分支继续深挖，无限嵌套。

线性聊天窗口里，问题越聊越偏、思路汇不拢；这里每个想法都是画布上的一个节点，
哪条线索值得深入就分叉哪条，哪条不需要就整枝剪掉。

## 核心功能

**对话与分支**
- ✂️ **划词分叉** — 在 AI 回答里选中一段文字，弹出面板，点「精简 / 完整」立即创建子分支并自动连线
- 🌳 **无限嵌套** — 子分支的回答同样可以划词继续分叉，思路树随对话生长
- 🎛️ **两种上下文模式** — 精简：只围绕选中片段展开；完整：继承祖先链全部对话 + 各级选中片段，可随时切换
- 🫧 **流式输出** — SSE 打字机效果，回答实时渲染 Markdown

**画布操作**
- 🖱️ **节点操作** — 卡片拖拽（连线跟随）、八向自由缩放、折叠/展开子树、重命名、删除含子树、右键菜单、批量操作
- 📐 **金字塔树形布局** — 根节点顶部居中、逐层向下展开，一键整理布局、适应视图
- 🗺️ **小地图** — 缩略导航，按分支着色；缩放百分比常驻画布底部
- ↩️ **撤销 / 重做** — 整树快照，误删分支可回退

**桌面端**
- 🫧 **桌面悬浮球** — 42px 应用图标球，始终置顶，自动贴边吸附；左键直达快速对话，右键开菜单
- 🪟 **快速对话小窗** — 独立置顶小窗，标题栏拖动移动、八方向自由缩放，位置与大小自动记忆
- 🖥️ **独立应用窗口** — 基于系统 WebView2 渲染，不依赖也不打开浏览器，无控制台黑窗

**数据与模型**
- 🤖 **多模型** — 任何 OpenAI 兼容 API（DeepSeek / 豆包 / 通义 / 智谱 / OpenAI…）、本地 Ollama、无 Key 演示模式
- 🔑 **多密钥档案** — 多套 Key 分组管理，支持真实连通性测试（校验 Key、测延迟、拉取可用模型一键切换）
- 🗂️ **多画布** — 多个话题并行互不干扰，可重命名、清空对话、删除画布
- 📤 **导出与备份** — Markdown、Mermaid、网页快照 HTML（含画布结构图）、JSON 备份与导入还原
- 💾 **数据自主** — 全部存本地 JSON 文件（桌面版）或浏览器 localStorage（单文件版），不经过任何第三方

## 本次更新（v1.1.0）

**桌面悬浮体验**
- 悬浮球改用应用图标外观，尺寸收敛到 42px，去掉黑色方块底
- 交互重排：左键直达快速对话，右键开菜单，点击窗口外自动收起
- 快速对话小窗支持标题栏拖动与八方向自由缩放（上/下/左/右 + 四角），带最小尺寸保护
- 小窗位置与大小持久记忆，下次展开回到原处
- 拖动缩放由后端跟随全局光标，光标移出小窗也不会中断

**画布操作**
- 左下角缩放百分比移至画布最底部，移除与其重叠的旧缩放控件
- 「清空」改为清空当前会话全部对话，只保留一个空白根会话（可撤销）
- 新增「删除画布」，二次确认即可，无需输入文字

**修复**
- 画布列表不再出现点不开的「未命名画布 (0)」
- 悬浮速记改为后端记住绑定画布，不再每次启动多出一个空白画布

## 下载与使用

| 文件 | 说明 |
|---|---|
| `BranchChatCanvas.exe` | Windows x64 单文件，约 40 MB |

双击运行 → 等待 5~10 秒（单文件解包）→ 打开独立应用窗口，不依赖也不打开浏览器。

**上手三步**：输入第一个问题生成根节点 → 在回答里划选一段文字 → 点「精简」或「完整」长出子分支。

- 数据保存在 exe 同级的 `data/` 目录，整个文件夹拷走即可带着对话记录迁移
- 端口自动挑选空闲值（8765 起），多开互不冲突
- 不填 Key 也可进演示模式

**校验（SHA256）**

```
e1af62761957c0e933c9a5ceeead1749601a47419222ae859719ae0a33aeaacf
```

## 已知限制

- 仅提供 Windows 版本；依赖系统 WebView2 运行时（Win10/11 通常自带）
- PyInstaller 未签名程序可能被 Defender 误报，选择「仍要运行」或加入白名单即可
- 首次启动解包需 3~8 秒属正常现象
