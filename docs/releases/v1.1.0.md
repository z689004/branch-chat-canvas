# v1.1.0 — 悬浮速记与画布操作打磨

> 把一次 AI 对话变成一棵可以持续分叉的树：在画布上提问，AI 流式回答；
> 划选回答中任意一句话，一键长出一个独立子分支继续深挖，无限嵌套。

本版聚焦**桌面端随手可用**：悬浮球更克制、快速对话窗可拖可缩、画布操作更顺手，
并修掉了画布列表里几个恼人的边角问题。

## 本次更新

### 桌面悬浮体验

- 悬浮球改用应用图标外观，尺寸收敛到 42px，彻底去掉黑色方块底
- 交互重排：**左键直达快速对话**，右键开菜单，点击窗口外自动收起
- 快速对话小窗支持**标题栏拖动**与**八方向自由缩放**（上 / 下 / 左 / 右 + 四角），带最小尺寸保护
- 小窗位置与大小**持久记忆**，下次展开回到原处
- 拖动与缩放由后端线程跟随全局光标计算，**光标移出小窗也不会中断**（此前向外拉大时会卡住）

### 画布操作

- 左下角缩放百分比移至画布最底部，并移除与其重叠的旧缩放控件
- 「清空」改为清空当前会话全部对话，**只保留一个空白根会话**（可撤销）
- 新增「删除画布」，二次确认即可，不再要求输入文字

### 修复

- 画布列表不再出现点不开的「未命名画布 (0)」：列表只认 `tree-*.json`，不再把配置文件当画布
- 悬浮速记改为后端记住绑定的画布，不再每次启动多出一个空白画布

## 下载与使用

| 文件 | 说明 |
|---|---|
| `BranchChatCanvas.exe` | Windows x64 单文件，约 40 MB |

双击运行 → 等待 5~10 秒（单文件解包）→ 打开独立应用窗口，不依赖也不打开浏览器。

- 数据保存在 exe 同级的 `data/` 目录，整个文件夹拷走即可带着对话记录迁移
- 端口自动挑选空闲值（8765 起），多开互不冲突
- 不填 Key 也可进演示模式

**校验（SHA256）**

```
e1af62761957c0e933c9a5ceeead1749601a47419222ae859719ae0a33aeaacf
```

## 已知限制

- 仅提供 Windows 版本；依赖系统 WebView2 运行时（Win10/11 通常自带）
- PyInstaller 未签名程序可能被 Defender 误报，选择「仍要运行」或加入白名单即可
- 首次启动解包需 3~8 秒属正常现象
